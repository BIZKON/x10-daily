**Решения владельца 13.08, которые надо беречь:**

- Темы растут из базы знаний плюс повестки, а НЕ из отклика: его 11 на 286
  статей, у нового клиента ноль.
- Горизонт — месяц, экран открыт на неделе. Строка плана — заготовка задания
  «Создать», а не запись в блокноте. Автовыход — вторым шагом.
- Один экран, ДВА режима показа. Оба читают один запрос и рисуют одну карточку;
  клик по клетке календаря уводит в ленту дня. Состояние экрана — в адресе.
- Режим по умолчанию — лента на любом экране: сервер не знает ширину окна, а
  угадывать значит иногда открыть сетку 7×4 на телефоне.

**🔴 Разведка данных, изменившая проект:** в `seen_items` лежат только отпечатки
для дедупа — ни заголовков, ни текстов. Реестр §3.3 рассчитывал на источник,
которого нет. Повестку берём из СВОИХ опубликованных статей за 30 дней: они
пришли из тех же лент клиента и уже отобраны конвейером. Тот же список работает
стоп-листом.

**🔴 План не собирается из пустой базы знаний.** Гейт в трёх местах: экран не
показывает кнопку, api отказывает сразу, воркер — последний рубеж. Из пустоты
вышли бы тридцать тем про отрасль вообще, за которые клиент заплатит.

### Два дефекта очереди публикаций — миграция и код готовы, не выкачены

Реестр §3.12. Спека — `docs/superpowers/specs/2026-08-13-publishing-queue-defects-design.md`.

**Миграция `0033`,** четыре изменения в `channels`: колонка `format` (post ·
carousel · video · host_video), колонка `status` (queued · posted · rejected) с
заполнением из `posted_at`, пара `rejected_at`/`rejected_reason`, уникальный
индекс переехал на `(article_id, channel, format)`.

**Код догнал миграцию:** очередь читается по статусу, формат ведёт через все
шаги слота, выбор строки вынесен в чистую `pickPostableRow`.

**🔴 Формат — ОБЯЗАТЕЛЬНЫЙ параметр** `markChannelPosted` и
`recordChannelFailure`. Без него условие `(article_id, channel)` пометило бы
опубликованными все строки материала разом. Компилятор поймал два старых вызова
ровно на этом.

стоит там намеренно, модель сама тянется к числу месяца. Проверять надо наличие
правила, а не отсутствие слова.

проверяемая логика экрана ушла в api, где тесты уже есть. Это же и по канону:
решение принимает сервер, а не вёрстка.

⚠️ **Живой прогон стоит рубль и находит то, чего не находят тесты.** Оба дефекта
