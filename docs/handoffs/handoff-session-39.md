## 1. Чем закончилась сессия

Платёжной трубы в коде не было вообще. Теперь клиент может заплатить сам —
картой или по счёту, — а комиссия партнёру начисляется без нашего участия.
Магазин включён на боевом магазине ЮKassa `1378536`.

Труба ОДНА на пополнение баланса и на продажу завода: одна таблица платежей,
один вебхук, одно место зачисления, различает назначение `payments.purpose`.

| Слой | Где |
|---|---|
| Шлюз | `apps/api/src/lib/yookassa.ts` |
| Зачисление | `apps/api/src/lib/payment-settle.ts` — две точки входа: вебхук и безнал |
| Вебхук | `apps/api/src/routes/billing.ts` |
| Заказ и ссылка | `routes/partner.ts` (партнёр) · `routes/admin-partners.ts` (владелец) |
| Страница клиента | `apps/miniapp/src/app/pay/[token]/` |
| Счёт | `apps/miniapp/src/app/pay/[token]/invoice/` |
| Презентация по ссылке | `apps/miniapp/src/app/p/[slug]/` |
| Уведомления | `apps/api/src/lib/payment-notify.ts` + `payment-messages.ts` |

Тестов: 321 в api (было 274 на старте магазина), 415 в pipeline, 146 в agents.

## 2. Решения владельца, принятые в этой сессии

| Вопрос | Решение |
|---|---|
| Магазин ЮKassa | Сразу боевой, тестовый пропущен |
| Юрлица | Счёт по реквизитам ИЛИ карта — на выбор клиента |
| Рассрочка | 50/50, работа с первого платежа, максимум 2 месяца |
| Страница оплаты | Наша: сумма, email, оферта → редирект в ЮKassa |
| Партнёры | Любые, включая физлиц. 20% грязными, НДФЛ удерживаем, взносы СФР сверх — наши |
| Цена заказа | Партнёр — только прайс. Владелец — любая сумма (он же и «скидка по согласованию») |
| Подтверждение заказа | Не требуется: ссылка сразу, владельцу уведомление |
| Нумерация | Сквозная с единицы, формат `0001` |
| Ссылка партнёра | Ведёт В МИНИ-АПП на презентацию, а не на статическое КП |
| Витрина программы | Деньгами, а не процентами: «до 70К», полоса сторис вверху ленты |

## 3. 🔴 Что осталось непроверенным

**Реальной оплаты через магазин не проходило.** Владелец выбрал прогон без
денег (16.08). Цепь «оплата картой → вебхук → зачисление → комиссия» проверена
по частям, но не целиком.

Как проверить за 10 ₽: заказ № 0001 уже заведён и живёт по ссылке
`https://app.pro-agent-ai.ru/pay/70TcZ7iMoGH9knDA` — оплатить картой, затем
сверить `deal_payments`, `partner_accruals` и статус сделки. Заказ помечен в
`note` как проверочный, убирается одним `delete`.

**Что подтверждено вживую:** связка ключей (боевой API ответил `404 payment
doesn't exist` вместо `401` — авторизация проходит), вебхук отвечает 200 на
мусор и чужой платёж, страница оплаты и счёт открываются, реквизиты и сумма
прописью печатаются верно.

## 5. Грабли, пойманные в этой сессии

**Пять слоёв env — три раза подряд.** `TG_OPS_CHAT_ID`, `TELEGRAM_BOT_USERNAME`
и оба ключа ЮKassa жили в схеме `packages/config/src/env.ts` и в compose, но не
были проведены в api. Уведомления молча не ушли бы, ссылка партнёра собралась бы
с запасным именем бота. Тест `apps/api/test/env-wiring.test.ts` теперь держит
семь ключей — добавляй туда каждый новый.

**Biome по каталогу цепляет чужие файлы.** Дважды за сессию `biome check --write
apps/miniapp/src` переформатировал семь посторонних модулей и утащил их в
коммит. Запускать только по своим путям, перед коммитом смотреть `git status`.

**`git add -A` в этом дереве опасен.** В индексе лежала чужая работа
(`landing/mobile-kp/`), дважды уехала в мой коммит. Коммитить перечислением
путей.

**Tailwind v4 не берёт голый класс с анимацией.** Правило `.story-pulse` в
`globals.css` в сборку не попало — пульсация молча не работала. Объявлять через
`@theme { --animate-<имя>: ... }`, класс тогда `animate-<имя>`.

**Cache Components требует `generateStaticParams`** для каждого динамического
сегмента, иначе сборка падает на «uncached data outside Suspense».

**Собранные КП под `.gitignore`** (`landing/*/`) — на прод они не переносятся
деплоем. Исправлено: `deploy.sh` пересобирает их на сервере (`node
scripts/build-kp.mjs`), для этого на VM поставлены `nodejs` и `imagemagick`, а
`partners.json` лежит рядом с `.env.production` (права 600).

**Живой прогон снова поймал то, чего не видели тесты:** блок графика показывал
«до 15.09 — 0 ₽» на последней части рассрочки; суммы рассрочки ломались на три
строки; публичный маршрут партнёра не попал в коммит (команда сорвалась на
недоступности классификатора) — страница шла без подписи.
