## 2. Чьи данные обрабатываются

каналов Заказчика в объёме, который предоставляет мессенджер.

## 3. Собираемые данные

### 3.1. Данные из Telegram

При входе через Telegram Сервис получает:

- идентификатор пользователя Telegram — обязательно, для входа;
- имя и username — при наличии, для отображения в кабинете;
- фотографию профиля — при наличии.

Сервис **не получает** доступ к номеру телефона, контактам и переписке.

### 3.2. Данные, создаваемые при работе

- материалы, подготовленные Сервисом, и правки к ним;
- решения о публикации: кто и что согласовал, когда;
- адреса источников, указанных Заказчиком;
- сведения о расходах и пополнениях Баланса.

### 3.3. Данные при оплате

Адрес электронной почты плательщика — обязателен для формирования кассового
чека. Данные банковской карты Оператору **не передаются и не хранятся**: их
обрабатывает платёжный сервис ЮKassa.

### 3.4. Технические данные

IP-адрес, тип устройства, дата и время обращений — для безопасности и
диагностики.

## 4. Цели обработки

Предоставление доступа к Сервису; разграничение прав внутри Команды Заказчика;
учёт расчётов; техническая поддержка; предотвращение нарушений; выполнение
требований законодательства.

- законные интересы Оператора (п. 7 ч. 1 ст. 6 ФЗ-152).

## 6. Где хранятся данные

🔴 Персональные данные хранятся в базе данных, размещённой в
**Российской Федерации** (managed PostgreSQL, дата-центр Москва). Требование
о локализации по ч. 5 ст. 18 ФЗ-152 соблюдается.

Каждый Заказчик получает **отдельный экземпляр системы с отдельной базой**:
данные разных Заказчиков физически не смешиваются.

## 7. Передача данных третьим лицам

### 7.1. Обработчики

| Кому | Что передаётся | Зачем |
|---|---|---|
| Timeweb (AI Gateway, РФ) | тексты подготавливаемых материалов | подготовка публикаций |
| Timeweb (хостинг и БД, РФ) | все данные Сервиса | размещение и хранение |
| Telegram | публикуемые материалы, служебные сообщения | публикация и управление |

Модели искусственного интеллекта вызываются **через шлюз Timeweb на
инфраструктуре Российской Федерации**. Персональные данные пользователей в
запросы к моделям не передаются: Сервис работает с публичными материалами
источников.

### 7.2. Иные случаи

Оператор может передать данные при наличии согласия субъекта, по требованию
законодательства или по запросу уполномоченных государственных органов.

### 7.3. Запрет на продажу

Оператор **не продаёт** персональные данные и не передаёт их в рекламных целях.
