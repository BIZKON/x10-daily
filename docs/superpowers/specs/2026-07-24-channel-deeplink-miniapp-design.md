# Спека 1 — Deep-link из канала в Mini App на конкретную статью

**Дата:** 2026-07-24
**Статус:** дизайн одобрен, ждёт написания плана
**Связано:** Спека 2 (ИИ-обложки) — использует ту же inline-кнопку канала.

---

## Цель

Читатель из канала «ИИ работает на вас!» одним тапом открывает Mini App
**внутри Telegram** сразу на той статье, о которой пост. Сейчас пост
заканчивается текстовой ссылкой «Читать в ProAgent AI →» на
`app.pro-agent-ai.ru/article/<slug>`, которая открывает **сайт** во встроенном
браузере, а не Mini App.

## Решения (из брейншторма)

- Deep-link ведёт на **конкретную статью** (не на общую ленту).
- Механика: **Main Mini App** бота + `startapp`-параметр.
- Разовая настройка Main Mini App в **@BotFather** — ручной шаг владельца
  (интерактивный, на его аккаунте; агент его выполнить не может).

## Механика Telegram (проверено веб-поиском 2026-07-24)

- Ссылка `https://t.me/<bot>?startapp=<param>` открывает **Main Mini App** бота
  и передаёт `<param>` в `Telegram.WebApp.initDataUnsafe.start_param` (и в
  GET-параметр `tgWebAppStartParam`).
- В **канале** нельзя использовать inline-кнопки типа `web_app` (они только в
  личных чатах). Открытие Mini App из канала — через **url-кнопку** на такую
  `t.me`-ссылку. Telegram распознаёт её и открывает Mini App.
- Ограничение `startapp`: символы `A-Za-z0-9_-`, до 512 символов. Слаги статей —
  транслит (латиница + цифры + дефисы), укладываются. При несоответствии —
  фолбэк (см. ниже).

## Архитектура

### Компонент A — Постинг (изменение в `apps/workers/pipeline`)

- `drain-post-slots` при отправке поста добавляет `reply_markup` с одной
  inline url-кнопкой: **«Открыть в ProAgent AI»** →
  `https://t.me/<TELEGRAM_BOT_USERNAME>?startapp=<slug>`.
- Кнопка ставится и на текстовый пост (`sendMessage`), и на фото-пост
  (`sendPhoto`, из Спеки 2).
- Текстовая ссылка «Читать в ProAgent AI →» внутри `articleToTelegramHtml`
  **остаётся** как запасной путь (клиенты без кнопок / пересланный пост), но
  меняет URL на тот же `t.me`-deep-link, а не на голый веб-домен. _Открытое:_
  оставить обе точки входа или только кнопку — решить при плане (по умолчанию —
  обе, кнопка приоритетна).
- Имя бота — из нового env `TELEGRAM_BOT_USERNAME` (без `@`). Прокинуть в
  `readBindingsFromEnv` (`apps/workers/pipeline/src/bindings.ts`) + compose +
  `@x10/config`-схему (грабля: новый env воркера).

### Компонент B — Роутинг в Mini App (изменение в `apps/miniapp`)

- Клиентский старт-хендлер читает `start_param` из
  `window.Telegram.WebApp.initDataUnsafe` (или `tgWebAppStartParam` из URL).
- Если `start_param` непустой и валидный slug → `router.replace('/article/'+slug)`.
  Навигация клиентская → PPR не затрагивается; читалка (`/article/[slug]`) уже
  готова.
- Валидация: `slug` матчит `^[a-z0-9-]{1,120}$`. Иначе — игнор, остаёмся на
  ленте (без 404-редиректа).
- Где: в `TelegramProvider` (или отдельный `StartParamRouter`-клиент-компонент,
  смонтированный в shell-layout). Срабатывает один раз на маунт.

## Поток данных

```
пост в канал (drain-post-slots)
  └─ reply_markup: url-кнопка → t.me/<bot>?startapp=<slug>
        └─ тап → Telegram открывает Main Mini App, start_param=<slug>
              └─ StartParamRouter читает start_param → router.replace(/article/<slug>)
                    └─ читалка статьи (уже существует)
```

## Что делает владелец (разовое, вне кода)

1. @BotFather → выбрать `@Sekretar_Syrov_IP_bot` → Bot Settings → Configure Mini
   App → задать URL `https://app.pro-agent-ai.ru` как Main Mini App.
2. Проверить, что `t.me/Sekretar_Syrov_IP_bot?startapp=test` открывает Mini App.

## Обработка ошибок / краевые случаи

- `start_param` пуст → обычный старт на ленте (текущее поведение).
- `start_param` невалиден/не-slug → игнор, лента (без падения).
- Статья по slug удалена/архивирована → читалка отдаёт 404 (существующее
  поведение `loadArticle` → `notFound()`).
- Клиент без поддержки кнопок → запасная текстовая deep-link-ссылка в теле.

## Тестирование

- Unit: билд url-кнопки (slug → корректный `t.me`-URL, экранирование).
- Unit: `StartParamRouter` — валидный slug роутит, невалидный игнорит, пустой
  не делает ничего.
- Live: реальный пост в тест-канал → тап кнопки открывает Mini App на статье.

## Вне scope

- Именованные Mini Apps (несколько web-app у бота) — не нужны, хватает Main.
- Смена бота на dedicated — отдельное решение (коуплинг auth+постинг).

## Метрологические бюджеты

- Изменение miniapp — только клиентский старт-хендлер (пара КБ), в 200KB-бюджет
  не бьёт. PPR-дыры не трогаются.
