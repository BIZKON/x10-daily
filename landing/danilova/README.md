# КП «Цифровой центр клиники Даниловой» — инструкция

**Живой адрес:** https://danilova-kp.website.twcstorage.ru/

Коммерческое предложение для детского педиатрического центра Елены Даниловой
(Резекне, Латвия): цифровой администратор, говорящие агенты на телефоне, боты
записи в Telegram/Instagram с кнопкой оплаты, нативные приложения iOS и Android,
контент-завод на двух языках, агенты финансов и потока, два личных наставника.
Цена 15 000 €, первый платёж 2 000 €, интерактивный калькулятор рассрочки
на 3/6/12 месяцев (остаток делится равными долями, хвост округления — в
последний платёж; любой сценарий сходится ровно в 15 000 €).

Собрано 20 августа 2026. Дизайн — система КП контент-завода
(`landing/kp/template.html`), но **генератором `build-kp.mjs` НЕ собирается**:
это отдельный ручной документ, править прямо здесь.

`index.html` самодостаточен: все стили, скрипты и SVG внутри файла, внешних
запросов нет. Открывается двойным щелчком.

Рядом лежит `audit-pienenite.md` — полный протокол аудита сайта клиента
(pienenite.lv). 🔴 Он в `.gitignore` намеренно: сводка сведений о живом
человеке не для публичного репозитория. Публикуется только index.html.

## Как выложить правку

Бакет `danilova-kp` в Timeweb Object Storage создан S3-клиентом (не `twc`,
иначе к имени добавился бы префикс аккаунта — см. README mobile-kp, там же
все грабли). Адрес не меняется, заливается поверх:

```bash
s3cmd -c ~/.s3cfg-twc put landing/danilova/index.html s3://danilova-kp/index.html \
  --acl-public --mime-type="text/html; charset=utf-8" \
  --add-header="Cache-Control: public, max-age=300"
```

Проверка (кэш 5 минут, добавьте ?v=):

```bash
curl -sS -o /dev/null -w "%{http_code}\n" "https://danilova-kp.website.twcstorage.ru/?v=$(date +%s)"
```

⚠️ Бакет не виден в панели Timeweb и в `twc storage list` — управлять только
S3-клиентом. Артефакт-копия для внутреннего просмотра:
https://claude.ai/code/artifact/cc8d54e5-e3da-42ee-8094-9521bdef45fa
